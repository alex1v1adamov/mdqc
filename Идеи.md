# Презентация: Платформа динамической бизнес-логики

## 🎯 Текущие возможности системы

### 📊 Мета-модель данных
- **Динамическое описание сущностей** (`MetaEntity`, `MetaAttribute`)
- **Гибкая система типов** (`BasicType`, `AttributeCategory`)
- **Поддержка перечислений** (`MetaEnum`, `MetaEnumValue`)
- **Бидирекциональные связи** между сущностями

### 🔧 Движок предикатов
- **Древовидная структура условий** (`PredicateNode`, `EvaluationOperationNode`)
- **Типобезопасные операции** (`OperatorType` с валидацией типов)
- **Навигация по связям** (`PathExpressionNode`)
- **Универсальное хранение значений** (`PredicateNodeValue`)

### 🛡️ Система безопасности
- **Ролевая модель доступа** (`UserRole`, `Permission`)
- **Динамические политики** на основе предикатов
- **Привязка прав к атрибутам** сущностей

### 🌍 Бизнес-домен
- **Геопространственные данные** (Point geometry)
- **Поддержка временных меток**
- **Готовые сущности** (Pet, Clinic)

## 🚀 Ключевые сценарии применения

### 1. **Динамические формы и валидация**
```java
// Frontend автоматически рендерит формы
// на основе MetaEntity и MetaAttribute
FormSchema schema = loadFromMetaEntities();
```

**Преимущество:** Бизнес-аналитики добавляют поля на фронтенд без программистов

### 2. **Бизнес-правила без перекомпиляции**
```java
// Условия скидок, одобрения заявок
// настраиваются через UI
Predicate discountRule = buildPredicateFromConfig();
```

**Преимущество:** Маркетологи настраивают акции самостоятельно

### 3. **Адаптивная аналитика**
```java
// Пользователи строят отчеты
// выбирая любые поля и фильтры
ReportDefinition customReport = createUserDefinedReport();
```
**Преимущество:** управление дашбордами на фронте.

### 4. **Гранулярная безопасность**
```
 Какие-то поля доступны для чтения или изменения для одной роли, каике-то - для другой.
```
**Преимущество:** Тонконастроенная модель доступа
